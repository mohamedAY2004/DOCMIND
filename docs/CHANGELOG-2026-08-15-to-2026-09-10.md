# DocMind changes since August 15, 2026

Snapshot: September 10, 2026. Sources: local Git history and the current working tree. This is a repository change log, not confirmation that these changes were deployed. Remote repositories were not fetched for this report.

There are **16 commits** in the requested period: 14 on August 17, one on August 18, and one on August 19. Together they changed **150 files**, with **8,381 added lines and 963 removed lines** (including lockfiles and documentation). No additional commits are recorded between August 20 and this snapshot. ## Committed product and infrastructure changes

### 1. Campus pilot data and runtime foundations — August 17, `b652abb`

- Added migrations 0006–0010 for grounded messages, rotating browser sessions, pilot quality data, stable message ordering, and active evaluation runs.
- Messages now persist citations, grounding status and generation status. Conversations carry retention deadlines. Uploaded files/materials carry storage metadata.
- Added evaluation, feedback and refresh-session models/repositories.
- Added shared ephemeral state with local/Redis support, telemetry recording, local/S3 storage support, retention service, purge command and retention worker.
- Extended configuration, dependencies, health reporting and admin deletion handling for these facilities.

### 2. Grounded streaming chat and citations — August 17, `cca6daa`

- Added real SSE responses for document chat, subject tutor chat and instructor previews.
- Added native streaming support to OpenAI, Gemini and Cohere adapters and the JSON planner agent.
- Introduced a reply lifecycle with persisted generating, complete, failed and cancelled states, plus generation concurrency/cancellation controls.
- Added numbered evidence validation, citation response schemas, grounding classification and authorized source-content access.
- Added structured feedback and English/Arabic prompt changes for grounded answers.
- Added backend regressions for provider/agent streams, citations, grounding, feedback, materials and chat cancellation.

### 3. Tutor evaluation and readiness workflows — August 17, `8919c2f`

- Added instructor-managed evaluation question banks and background evaluation runs.
- Added advisory subject readiness, conversion of reviewed feedback into evaluation cases and admin access to quality results.
- Added evaluation API schemas/routes/services, a worker and tests for readiness, feedback and execution.

### 4. Browser identity and request protection — August 17, `6ffc1f8`

- Added rotating browser cookie sessions and refresh-session handling.
- Replaced the portal's URL-token handoff with one-time SSO codes.
- Added CSRF protection, Redis-backed request limits and production startup checks.
- Updated authentication dependencies, API contracts and security regressions.

### 5. Instructor/admin quality dashboards — August 17, `789f12f`

- Added instructor evaluation panels for readiness, cases and runs.
- Added an admin quality-report page with run comparisons and failed-case inspection.
- Connected quality views to the evaluation API, added component tests and loaded report-generation tooling on demand.

### 6. Streaming and source-aware web experience — August 17, `c7f4288`

- Moved web authentication to cookie/refresh/CSRF handling and added portal-code exchange.
- Replaced simulated response typing with actual SSE transport, with buffered fallback, stop and retry controls.
- Added source drawers, citation rendering and structured feedback dialogs.
- Improved responsive chat history and accessible controls.
- Added route/report lazy loading, theme handling, dependencies and Vitest coverage for chat/auth/source/feedback behavior.

### 7. Mobile response compatibility — August 17, `d84ce45`

- Extended Flutter DTOs to parse citations, grounding and generation metadata with compatibility defaults.
- Added a message-contract test. This commit did **not** display the new metadata in the mobile UI; that is part of the current uncommitted refactor.

### 8. Pilot packaging and trusted portal demo — August 17, `8632eaf`

- Added deployment composition for the web app, API, migration job and workers.
- Added the frontend Dockerfile, Nginx configuration, Docker ignore rules and CI acceptance jobs.

## Current maintainability work — uncommitted at this snapshot

These changes exist in the working tree. They are implementation work in progress, not completed releases. The requested focused commits have not yet been created.

### Backend

- Removed the `/api/v1/*` debug route tree and its exclusive controllers, models and schemas; removed the extra application database pool. Official `/api/chat/*` compatibility routes remain.
- Moved `RetrievedChunk` into the vector-store package and removed Qdrant's dependency on legacy controllers.
- Added a conservative legacy-data cleanup command and migrations to adopt the fixed vector schema and retire empty legacy tables. Cleanup safety, interruption handling and migration preservation tests are still being completed. No production cleanup or deployment has been performed.
- Centralized instructor-preview checks for subject assignment, administrator access, semester state and processed materials across both transports.
- Corrected Cohere construction, deterministic Qdrant identifiers and failed vector-write handling; indexing retries use stable chunk IDs and clear partial material writes.
- Added shared RAG composition, subject corpus preparation, answer generation and streaming lifecycle modules. Buffered lifecycle consolidation remains in progress.
- Removed application-time vector-table/index DDL in favor of migrations.
- Moved analytics/retention queries into repositories; subject statistics use grouped aggregates and SQL pagination.
- Added optional ascending/descending message history, preserving ascending as the default. Added server-side admin-user sorting.
- Removed confirmed unused backend helpers and made PostgreSQL fixtures opt-in for tests that need them.

### Web

- Replaced duplicate document/tutor/preview streaming state handling with a shared session hook and thin adapters.
- Added request ownership and abort handling for conversation switching, component unmount, list operations, material loading, uploads, mutations and file polling.
- Preserved failed drafts/partial replies and prevented delayed responses from changing the newly selected conversation or subject.
- Preserved page envelopes, rejected malformed API responses, added conversation-list pagination, loaded recent history first and added “Load older messages” with scroll preservation.
- Replaced fixed admin record caps with paginated loading; dropdown/report consumers can explicitly collect all pages.
- Extracted material and document-file state from large pages into dedicated hooks.
- Moved theme/base/component rules into Tailwind configuration, imported vendor CSS at the entrypoint and replaced handwritten inline styles with utilities or native SVG/progress attributes.
- Removed unused hooks, barrels, exports, components and a dependency. Added Knip unused-export checking and request-race/pagination regressions.

### Mobile

- Installed project-local Flutter 3.35.7 and recorded the version for reproducible tooling.
- Made the active chat repository own both sending and history. Removed the competing inactive document-message implementation while preserving registered route aliases.
- Moved construction into GetX bindings and injected use cases into controllers. Standardized repository results as `Either<Failure, T>` with authentication, readiness, validation, permission, network and unexpected failures.
- Removed HTTP/storage implementation dependencies from use cases and moved visual styling out of domain entities.
- Added one shared DTO-to-domain mapping path for citations, grounding and generation status from sending and history.
- Added source details, failed/interrupted reply states, draft preservation and retry, explicit history errors and older-history loading to the UI.
- Replaced readiness inferred from messages with serial polling of the actual file endpoint, stopping on completion, failure, navigation or disposal.
- Replaced payload logging with development-only sanitized method/route/status/timing diagnostics; removed payload-logging dependencies.
- Removed unreachable shared libraries and obsolete feature-specific error classes; formatted Dart code.
- Added tests for injected controllers, stale requests, delivery failure/retry, readiness polling, disposal, logging and metadata mapping.
